# Auditoria de runtime da aplicação — fase somente auditoria

Data: 2026-09-17. Escopo: código carregado pela API Node/Express, SPA Vite, documentos de baseline/inventário e rotas/jobs referenciados. Não foram executados testes, chamadas a produção, uploads, envios de e-mail, jobs, limpeza ou alteração de código/configuração.

## Evidência operacional disponível

- Produção observada historicamente: uma API Node/Express residente, PostgreSQL interno, WebSocket Socket.IO, SMTP inicializado no processo, sem Redis/Bull/MinIO/S3 em execução. O tráfego da amostra era essencialmente healthcheck; pico, throughput de usuários, filas, DNS/SMTP real, uploads e WebSocket ativo são **NOT MEASURED**.
- `backend/src/index.ts` é a entrada confirmada: conecta banco, inicializa `monitoringService`, SMTP, `domainVerificationInitializer` e handlers de shutdown. `HealthCheckScheduler` também é importado e se arma automaticamente fora de testes (`scheduler/healthCheckScheduler.ts:308-326`).
- Frontend é React/Vite, sem SSR/Next.js (`frontend/package.json`, `vite.config.ts`). Não há cache Next/Image a auditar.
